qnap-exporter polls {{ .Values.nas.snmp.address }} every {{ .Values.nas.scrapeInterval }} with Grafana Alloy
and remote-writes the metrics to {{ .Values.grafanaCloud.prometheusUrl }}
with instance="{{ .Values.nas.hostname }}".

To open the Alloy UI and check component health:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  {{- range .paths }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ .path }}
  {{- end }}
{{- end }}
{{- else }}
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "qnap-exporter.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
  echo http://127.0.0.1:{{ .Values.service.port }}
{{- end }}

Import dashboards/qnap-dashboard.json into Grafana Cloud to view the metrics.
